# Omnigent conference demo

Presenter-led demo showing how Omnigent coordinates multiple coding-agent harnesses around a small GitHub API client.

Read [Meta-Harness: the Missing Layer Above Claude Code, Codex, and Pi](https://omnigent.ai/blog/meta-harness-missing-layer) for the full narrative behind the demo.

Start with [`PRESENTER.md`](PRESENTER.md). The client under `issue-triage/` is intentionally naive: it reads one GitHub Issues API page and does not distinguish pull requests from issues.
